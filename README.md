# Keep It Up! Cheat Pack

Unofficial one-click cheat mod for **Keep It Up!** (Steam, Windows): god mode, infinite lives, balloon control, super slap, speed/jump, fly/noclip, room skip, cosmetics unlock, a hotkey set and a control panel.

**Full guide, hotkeys, FAQ and troubleshooting: see the project page** (GitHub Pages for this repo).

## Quick start
1. Download `KeepItUp-Cheat-Installer.zip` from the [latest release](../../releases/latest) and extract the whole zip.
2. Close the game and run `Install.bat`.
3. Start the game from Steam. The control panel opens by itself.

Needs Windows and the game on Steam. The panel needs Python 3 (the installer offers to install it); hotkeys work without it.

## Uninstall
Run `Uninstall.bat`.
