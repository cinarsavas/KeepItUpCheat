Keep It Up! Cheat Pack

An unofficial mod for the Steam co-op balloon game: god mode, infinite lives, balloon control, super slap, speed, fly and more. Installs in one double-click, with hotkeys and a control panel.

What you get

Every feature has a hotkey and a button in the control panel.

God mode

Uses the game’s own developer cheat, so the balloon can drop without ending the run.

Infinite lives

Keeps your lives topped up to 99, and the panel can add +1, +5 or +25 on demand.

Balloon control

Stop it from ever touching the ground, freeze it in mid-air, pull it to your crosshair, or bring it to you.

Super slap

Stronger hits, longer reach and no cooldown. Every multiplier is adjustable with a slider.

Speed and jump

Faster walking and sprinting plus higher jumps, with separate sliders for each.

Fly / noclip

Float around, walk through geometry, and nudge up or down. Includes a forward dash.

Skip rooms

Trigger the elevator skip, or teleport to the game’s built-in developer waypoints.

Unlock cosmetics

Unlocks every cosmetic in one click.

Control panel

A small always-on-top window with live status: lives, room, balloon count and whether you are solo, host or guest.

Install

Takes about 30 seconds. You need the game on Steam, on Windows.

  1. Download and extract. Get KeepItUp-Cheat-Installer.zip from the button above and extract the whole zip (right-click → Extract All). Do not run it from inside the zip.
  2. Close the game, then run Install.bat. It finds the game in any Steam library. If it can’t, a folder window opens: pick the game folder (the one that contains ProjectLiftoff.exe).
  3. Start the game from Steam. The control panel opens by itself. Play in Windowed or Borderless mode so the panel is visible over the game.
Python (optional, for the panel only). The panel window needs Python 3. The installer checks for it and can install it with winget. Without Python everything still works through the hotkeys. If the panel doesn’t open the first time after installing Python, restart Steam once so it picks up the new install.

What the installer changes

Inside …\ProjectLiftoff\Binaries\Win64\ it adds dwmapi.dll and a ue4ss folder (the mod loader plus this mod). It never touches game files, saves or Steam itself. If you already have UE4SS there, it keeps your install and only adds the mod.

Manual install

Prefer to do it by hand? Open the zip’s payload folder and copy its contents (dwmapi.dll and the ue4ss folder) into ProjectLiftoff\Binaries\Win64\, next to ProjectLiftoff-Win64-Shipping.exe. The mod is already enabled in the bundled mods.txt.

Uninstall

Run Uninstall.bat. It removes the mod, and removes UE4SS too only if the installer was the one that added it.

The control panel

A separate window that talks to the mod through two small text files, so it can never crash the game.

Cheats tab

Checkboxes for every toggle that follow the real in-game state (they update when you use a hotkey), action buttons, lives buttons, movement buttons and a waypoint picker.

Strength & settings tab

Sliders for speed, sprint, jump, slap force, slap reach, fly speed, dash distance and the up/down step. Changes apply a moment after you let go.

Status line

Shows Connected plus lives, room, balloon count and mode (solo, host or guest). It closes itself about 45 seconds after the game exits.

Don’t want it to open automatically? In ue4ss\Mods\KeepItUpCheat\Scripts\main.lua set AUTO_LAUNCH_PANEL = false. You can still open KeepItUpPanel.pyw by hand.

Solo, host and guest

Co-op games let the host’s copy of the game decide most things, so what works depends on your role.

Be honest with your friends. The author tested the mod in solo on the demo. Host and guest behaviour comes from how the game’s code is built, not exhaustive testing. As a guest, some requests go through the game’s server calls, and the host may ignore them. Please don’t use it to spoil other people’s games.
No anti-cheat. The game folder contains none, so offline and private-lobby use has no ban system to trip. Use it at your own risk anyway, and stay out of public matchmaking.

Troubleshooting

Most problems are answered here. The log is always at …\Binaries\Win64\ue4ss\UE4SS.log.

Nothing happens in game / no hotkeys

Check that dwmapi.dll sits right next to ProjectLiftoff-Win64-Shipping.exe and the ue4ss folder is beside it. Open UE4SS.log and look for Loaded v1.3. If it’s missing, run Install.bat again. Hotkeys only work while you are in a level, not in the main menu.

The panel doesn’t open
  • The log line Launching panel: ok means the mod tried. Make sure Python 3 is installed (python.org, tick “Add python.exe to PATH”), then restart Steam once.
  • Open KeepItUpPanel.pyw by hand: right-click → Open with → Python, tick “Always use this app”.
  • The panel is hidden behind the game: switch the game to Windowed or Borderless.
The panel says “Waiting for game” or “Folder not found”

Click the Strength & settings tab → Browse and pick …\ue4ss\Mods\KeepItUpCheat. “Waiting” while the game is running means the mod isn’t loaded: see the first item.

The game crashes on launch

Send the last 50 lines of UE4SS.log in an issue. As a quick test, run Uninstall.bat: if the game then starts normally, the mod loader is the cause. Also try an antivirus exception for the game folder (below).

Antivirus flags dwmapi.dll

UE4SS loads by replacing the dwmapi.dll the game would normally pick up, which security tools sometimes treat as suspicious. It is open source (UE4SS-RE/RE-UE4SS). Add the game folder as an exclusion if yours quarantines it, then run the installer again.

A game update broke it

The mod relies on the game’s internal class names, so an update can change them. Uninstall until a new version is posted, and open an issue with the new game version. Updated class dumps make fixes fast.

Fly / noclip: I’m stuck or can’t pick things up

Noclip turns collision off, which also disables room triggers and pickups. Turn it off (F8) to progress; you’ll drop back to normal movement.

A cheat does nothing

Press F11 in the level, then check UE4SS.log. Each action logs which method it used (cheatmgr, rpc or direct) or why it failed. Attach that when you open an issue. If you’re a guest in someone else’s lobby, see Solo, host and guest.

How it works

For the curious and for anyone who wants to fix or extend it.

The pieces

  • UE4SS (build v3.0.1-1190-gf673aac0) is a mod loader for Unreal Engine games. It hooks in through dwmapi.dll and runs Lua mods.
  • KeepItUpCheat is a Lua mod (Scripts/main.lua). It registers the hotkeys and re-applies held effects every 400 ms.
  • KeepItUpPanel.pyw is a Python/Tkinter window. It sends commands to the mod and shows its state.

Why it needs so few guesses

The shipped game contains its own developer cheat manager (PLCheatManager: god mode, add life, elevator skip, unlock cosmetics, waypoint teleport…) plus matching server calls on the player controller. The mod calls those first, then falls back to the server RPC, then to setting values directly, and logs which path worked.

The panel link

gui_cmd.txt    panel → mod    "<id> set god 1", "<id> act skip_room", "<id> cfg speedMult 3.0"
gui_state.txt  mod → panel    key=value lines (lives, room, toggles, settings…), ends with END

Command ids only ever increase, and the mod ignores anything already in the file when it starts, so a restart never replays old commands. All numeric settings are clamped to safe ranges.

Tested with

Keep It Up! Demo on Steam, Unreal Engine 5.7.4, Windows. Other versions of the game may need an updated mod.

Build from source

The mod is plain Lua and the panel is plain Python, so there is no build step. Copy Mods/KeepItUpCheat into ue4ss/Mods. In UE4SS’s settings, EnableHotReloadSystem = 1 lets you reload the mod from the UE4SS window while the game runs.
